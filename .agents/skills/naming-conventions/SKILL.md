# Instructions

* Use naming conventions seen throught our code, and those listed below.
* If you see an existing object that doesn't follow conventions, you may ask
  the user if you can rename it.

# Naming conventions

### Files.

- Scripts meant to be run with Maxima should have a name starting with ms-.

### Variables

- In Maxima scripts, the _c suffix is typically used to indicate a list of DG
  expansion coeffiients, while _e is typocally used to indicate an expansion (expression).
